# 九格投注记录器：自动生成 APK

这个工程已经配置好 GitHub Actions。上传到 GitHub 后，会自动编译 APK。

## 最简单操作

1. 在 GitHub 新建一个空仓库。
2. 把本工程解压后，把里面所有文件上传到仓库根目录。
3. 提交后，GitHub 会自动开始编译。
4. 打开仓库的 **Actions** 页面，进入 **Build APK**。
5. 等待任务显示绿色成功。
6. 打开这次运行记录，在页面底部 **Artifacts** 下载 **九格投注记录器-APK**。
7. 解压下载的文件，即可得到 `.apk`，发送到安卓手机安装。

如果没有自动开始，也可以在 Actions → Build APK → Run workflow 手动运行。

## 注意

这是 debug APK，仅用于自己安装和测试，不是发布到应用商店的正式签名包。
